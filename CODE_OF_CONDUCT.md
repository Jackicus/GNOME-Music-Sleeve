# Code of Conduct

Music Sleeve is a GNOME app, and everyone taking part in it (issues, pull requests, reviews
and translations) is expected to follow the
[GNOME Code of Conduct](https://conduct.gnome.org).

To report a problem with someone's conduct here, email the maintainer at the address on
their [GitHub profile](https://github.com/Jackicus). Reports are kept confidential.
